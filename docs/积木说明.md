# 积木说明（content/video.ts 的写法）

一条视频 = 一个 `content/video.ts`。它是一份数据：把口播文案切成若干**段**（scene），每段配一种画面。
画面、配音、字幕、镜头、排版全部由工具包自动完成，你只需要写清楚“这一段地图上有什么、说到哪个词时出现”。

完整的例子：`content/examples/三国合伙人-颍川士族.ts`（样片那条）、`content/examples/官渡之战-示例.ts`。

---

## 1. 文件骨架

```ts
import type {Video} from '../src/core/types.ts';

const video: Video = {
  title: '官渡之战',          // 视频标题（也是输出文件名）
  seal: '频道名',             // 右上角竖排红色印章，1~5 个字（不写就没有）
  cast: {                    // 只写“人物表”里没有的人（见第 6 节），没有就整行删掉
    逢纪: {color: 'gold', hat: 'guan', face: 'beard', prop: 'scroll'},
  },
  scenes: [
    {type: 'map', script: '……这一段的口播原文……', territories: [...], items: [...]},
    {type: 'title', script: '……', title: '官渡之战', tag: '第三期', cast: ['曹操', '袁绍']},
    // ……
  ],
};

export default video;
```

可选：`voice: {name: 'zh-CN-YunxiNeural', rate: '+20%'}`（配音音色和语速，默认就是这个）；
`readAs: {'原文': '读法'}`（配音读错字时用同音字纠正，只影响声音，字幕不变）。

---

## 2. 最重要的规则

1. **script 必须是原文案原样切出来的。** 所有段的 script 按顺序连起来，要和 `口播文案.txt` 一字不差（标点也不能改）。`npm run check` 会核对。
2. **一段 = 一个画面意思**，一般 1~3 句、3~10 秒（20~50 个字）。超过 14 秒会提示拆段。
3. **when = 说到哪个词时发生。** 写法：从**这一段自己的 script** 里原样摘一个词，2~4 个字最好，例如 `when: '官渡'`。
   - 必须是这一段里有的字，不能改字、不能用别的段的词。
   - 同一个词在这段出现两次，想用第二次那个：`when: '袁绍#2'`。
   - 不写 when 的人物 / 城池 / 地名牌 = 这一段一开始就在。
   - 几样东西写同一个 when 没问题，它们会一起出现（例如 `when: '孙刘联军'` 同时弹出周瑜和刘备）。
   - 人物的 cross（打红叉）、mark（冒问号）、moodAfter（换表情）、moveTo（走动）要用人物出现**之后**才说到的词（或同一个词）。
4. **能在地图上演示的都用 map。** title / balance / list 三种卡片加起来不要超过总段数的一半，否则像 PPT。
5. **让画面一直在动。** 每段至少 2~3 个跟着口播出现的变化（人物弹出、走动、打叉、盖红印、版图拼出 / 换色、箭头……），不要有 3 秒以上的空档。
6. 地点写地名（`'洛阳'`），地名表里没有就写 `[经度, 纬度]`。人名写人物表里的名字，没有就在 `cast` 里补。
7. 镜头、人物之间的间距、躲开标题条和字幕，都是自动的，不用管坐标精确到哪里。

## 3. 四种段落

| type | 用途 | 必填 |
| --- | --- | --- |
| `map` | 地图讲解（主力，大部分段都用它） | script |
| `title` | 片头标题卡（漫画爆炸底 + 大标题 + 人物） | script, title |
| `balance` | 天平：两个人 / 两股力量的对比、互相依存 | script, left, right |
| `list` | 方格纸要点清单（总结、几个原因） | script, title, points |

### 3.1 map（地图）

```ts
{
  type: 'map',
  script: '公元200年，曹操和袁绍在官渡决战。',
  territories: [                                  // 势力版图（不写 = 沿用上一段地图的版图）
    {regions: ['冀州', '青州', '幽州', '并州'], color: 'gold'},
    {regions: ['兖州', '豫州'], color: 'blue', appear: '曹操'},
  ],
  items: [                                        // 地图上的东西
    {type: 'figure', who: '曹操', at: '官渡', when: '曹操'},
    {type: 'figure', who: '袁绍', at: '黎阳', when: '袁绍'},
    {type: 'battle', at: '官渡', when: '决战'},
  ],
  banner: {text: '官渡决战', style: 'red', when: '决战'},   // 顶部标题条（可选）
  year: {year: '公元200年', era: '建安五年'},             // 左上年份牌（可选）
}
```

**territories 势力版图**（六边形格子拼成的一块块势力）

| 字段 | 说明 |
| --- | --- |
| `regions` | 用哪几个州拼：司隶 豫州 兖州 徐州 青州 冀州 幽州 并州 凉州 益州 荆州 扬州 交州 |
| `around` | `{at: '颍川', radius: 1}` 以某地为中心、半径几度（0.3~6）的一圈。和 regions 一起写 = 只取这几个州里的那一圈 |
| `color` | 势力颜色，见第 5 节 |
| `appear` | when：说到这个词时，格子一块块飞进来拼合（不写 = 一开始就在） |
| `recolor` | `{color: 'blue', when: '拿下', from: '官渡'}` 说到这个词时整块换颜色，从 from 那里像潮水一样推过去（from 可省略） |

- 列表里**后面的版图会盖住前面的**：先写大势力，再写里面的小块（例如先写整个曹魏，再写颍川一圈）。
- **沿用规则**：一段**不写** territories = 原样沿用上一段地图的版图（上一段换过色的按换色后的颜色）。
  一段**写了** territories = 这一段只显示写的这些（不会和上一段合并）。所以凡是这一段要拼合（appear）或换色（recolor）的，都要把这一段想显示的版图**全部**重新写一遍，例如：

```ts
// 第 1 段：两块版图
territories: [{regions: ['冀州', '青州', '幽州', '并州'], color: 'gold'}, {regions: ['兖州', '豫州'], color: 'blue'}],
// 第 2、3 段：不写 territories，自动沿用
// 第 4 段：袁绍的地盘换成曹操的颜色 → 两块都要重新写，换色的那块加 recolor
territories: [
  {regions: ['兖州', '豫州'], color: 'blue'},
  {regions: ['冀州', '青州', '幽州', '并州'], color: 'gold', recolor: {color: 'blue', when: '拿下', from: '官渡'}},
],
// 第 5 段：不写，沿用（袁绍那块现在已经是蓝色）
```

- 一个州只能整块一个颜色。**只占了半个州**（例如赤壁之后刘备占荆州南部、曹操占荆州北部）就用 around 画一圈，后写的盖住先写的：
  `{regions: ['荆州'], color: 'green'}, {regions: ['荆州'], around: {at: '襄阳', radius: 1.5}, color: 'blue'}`。
- 常用组合（照抄就行）：河北四州 = `['冀州', '青州', '幽州', '并州']`；中原 = `['司隶', '豫州', '兖州', '徐州']`；北方 = 河北四州 + 中原；江东 = `['扬州']`；巴蜀 = `['益州']`；西凉 = `['凉州']`。
- 版图只是示意，拿不准当年谁占哪里时，宁可少画一块，不要画错。

**items 地图上的东西**

| type | 写法 | 画面 |
| --- | --- | --- |
| `figure` 人物 | `{type: 'figure', who: '荀彧', at: '邺', when: '荀彧'}` | Q 版棋子 + 头像名牌，弹出来 |
| `city` 城池 | `{type: 'city', at: '许', label: '许都', when: '许都', size: 'small'}` | 红墙宫殿，从上面落下；label 最多 5 字；size: 'big'（默认）/ 'small' |
| `label` 地名牌 | `{type: 'label', at: [113.85, 34.45], text: '许县', when: '许县', swap: {text: '许都', when: '改名'}}` | 白底毛笔字牌子；swap = 说到某词时翻面换字；`dark: true` 深色牌 |
| `stamp` 红印 | `{type: 'stamp', at: '颍川', text: '天使投资', when: '天使投资'}` | 红色印章砸下来，2~4 个字 |
| `arrow` 箭头 | `{type: 'arrow', from: '邺', to: '官渡', when: '南下'}` | 红白虚线弧形箭头（行军、进攻、投奔） |
| `battle` 交战 | `{type: 'battle', at: '官渡', when: '决战'}` | 交叉双刀 |

人物（figure）的额外动作，都是可选的：

| 字段 | 写法 | 效果 |
| --- | --- | --- |
| `mood` | `'happy'`（默认）/ `'neutral'` / `'worried'` / `'angry'` | 表情 |
| `mark` | `{kind: '?', when: '为什么'}`，kind 可以是 `'?'` `'!'` `'…'` | 头顶冒问号 / 感叹号 / 省略号气泡 |
| `moveTo` | `{at: '东郡', when: '投奔', arrow: true}` | 说到这个词时一跳一跳走过去；arrow: true 同时画虚线箭头 |
| `cross` | `'看透'`（一个 when） | 说到这个词时打红叉（失败、被抛弃、死亡） |
| `moodAfter` | `{mood: 'worried', when: '看透'}` | 说到这个词时换表情 |

- 好几个人写在同一个地点没关系，会自动排成一排（按写的顺序从左到右），也会自动让开城池、红印、地名牌。
- 红印、地名牌、城池、交战不会自动挪位置，坐标写在哪就画在哪；和人物挤在一起时是人物让开。红印一般放在人物旁边半度到一度的空地上（例如人物在 `[115.0, 35.7]`，红印写 `[115.8, 35.9]`）。
- 一段里的地点隔得太远（比如成都和辽东），镜头会拉得很远、人很挤，检查会提示拆段。

**叠在地图上的卡片**（都可选，每个最多一个）

| 字段 | 写法 | 位置 |
| --- | --- | --- |
| `banner` 标题条 | `{text: '人才交易所', style: 'slate', when: '交易所'}` | 顶部中间，最多 10 字；style 见下 |
| `year` 年份牌 | `{year: '公元191年', era: '初平二年', when: '191'}` | 左上角；year 最多 8 字，era 最多 6 字 |
| `person` 人物卡 | `{who: '荀彧', zi: '字文若', line: '颍川颍阴人 · 首席谋士', source: '《三国志·荀彧传》', when: '荀彧'}` | 左侧；line 最多 18 字 |
| `source` 史料卡 | `{book: '《三国志·魏书十·荀彧传》', date: '初平二年（公元191年）', quote: '彧去绍从太祖。【太祖大悦曰：“吾之子房也。”】', when: '大喜'}` | 右侧；quote 最多 52 字，用【】括起来的部分会被红线划重点 |

- `person` 和 `source` 同一段只能用一个（两边都挡住地图就没地方了）。
- banner 的 style：`'slate'` 蓝灰（默认，中性介绍）、`'red'` 红（重点、冲突、结论）、`'black'` 黑（对比、严肃）、`'purple'` 紫（皇室）、`'wood'` 木色（清单）。
- 不写 when 的 banner / 人物卡 / 史料卡在这一段开头出现。

**camera 镜头**（一般不用写）：镜头会自动对准这一段的人物、标记和正在拼合 / 换色的版图，并躲开标题条、卡片、字幕。
想要开场大全景时可以写 `camera: {center: '许', span: 20}`（span = 画面横向跨几度经度：6 ≈ 一个郡，12 ≈ 两三个州，20 ≈ 中原，30 ≈ 全国）。

### 3.2 title（片头标题卡）

```ts
{type: 'title', script: '今天咱们聊聊，三国第一大股东：颍川士族。', title: '三国合伙人', tag: '第一期 · 颍川士族', cast: ['荀彧', '曹操', '汉献帝']}
```
title 最多 7 字，tag 最多 14 字，cast 写 1~3 个人（中间那个最大）。一条视频一般只用一次，放在开场钩子之后。

### 3.3 balance（天平对比）

```ts
{
  type: 'balance',
  script: '曹操握着枪杆子，士族握着笔杆子，谁也离不开谁。',
  left: {who: '曹操', label: '枪杆子', when: '曹操'},
  right: {who: '荀彧', label: '笔杆子', when: '士族'},
  banner: {text: '枪杆子 + 笔杆子', style: 'black'},
}
```
label 最多 5 字。天平先晃两下再持平。

### 3.4 list（要点清单）

```ts
{
  type: 'list',
  script: '袁绍输在三点：犹豫不决，内部争斗，后方被烧。',
  title: '袁绍输在哪',
  points: [
    {text: '犹豫不决', who: '袁绍', when: '犹豫'},
    {text: '内部争斗', when: '内部'},
    {text: '后方被烧', when: '烧'},
  ],
}
```
2~4 条，每条最多 12 字，每条都必须写 when（说到哪条，哪条弹出）。who 可选（前面加头像）。title 最多 10 字。

## 4. 人物

- **预置人物**直接写名字：曹操、刘备、孙权、诸葛亮、关羽、张飞、袁绍、董卓、吕布、汉献帝……完整列表见 `docs/人物表.md`。
- 还有不写真名的群像：士兵、武将、谋士、文官、皇帝、女子、百姓。
- 名牌上显示的就是 who 写的名字，所以名字要短（最多 5 字）。

## 5. 颜色（势力 / 阵营）

| color | 颜色 | 习惯用法 |
| --- | --- | --- |
| `blue` | 蓝 | 曹操 / 曹魏 |
| `green` | 绿 | 刘备 / 蜀汉 |
| `red` | 红 | 孙氏 / 东吴 |
| `gold` | 金黄 | 袁绍、袁术 |
| `dark` | 黑灰 | 董卓、吕布、反派、衰落 |
| `purple` | 紫 | 汉室、皇帝 |
| `slate` | 蓝灰 | 士族、中立、地方豪强 |
| `brown` | 棕 | 刘表、刘璋、马腾等各地诸侯 |

人物的名牌和底座颜色 = 他在人物表里的 color；版图颜色 = territories 里写的 color。同一势力两边用同一个颜色。

## 6. 人物外观（cast，只给人物表里没有的人写）

```ts
cast: {
  荀氏: {color: 'slate', hat: 'guan', face: 'longbeard', prop: 'scroll'},
  甄宓: {color: 'blue', hat: 'hairpin', face: 'none', prop: 'fan'},
},
```

| 字段 | 可选值 |
| --- | --- |
| `color` | 见第 5 节（必填） |
| `hat` | `guan` 冠（文官、贵族，默认）/ `crown` 冕旒（皇帝）/ `bun` 发髻（年轻谋士、隐士）/ `helmet` 头盔（武将）/ `hairpin` 女子发髻 / `none` |
| `face` | `none` 无须 / `mustache` 八字胡 / `beard` 山羊胡 / `longbeard` 长须 |
| `prop` | `none` / `scroll` 竹简 / `sword` 剑 / `fan` 羽扇 / `brush` 毛笔 / `spear` 长枪 |
| `skin` | `normal`（默认）/ `red` 红脸 / `dark` 黑脸 |
| `robe` | 袍子颜色 `'#5B78A8'`（不写按 color 自动配） |

## 7. 字数上限（超过会报错）

| 位置 | 上限 | 位置 | 上限 |
| --- | --- | --- | --- |
| banner.text | 10 | title.title | 7 |
| stamp.text | 4 | title.tag | 14 |
| label.text | 6 | balance label | 5 |
| city.label | 5 | list.title | 10 |
| year.year | 8 | list 每条 | 12 |
| year.era | 6 | person.line | 18 |
| source.quote | 52 | source.book | 16 |
| seal | 5 | 人名 | 5 |

数字和英文按 0.6 个字算。

## 8. 写分镜的套路（参考样片）

1. **开场钩子**（map）：先抛结论或反常识的问题，全国 / 大区地图，势力版图拼出来，主角弹出，盖一个红印点题。
2. **片头标题**（title）：节目名 + 本期标题 + 2~3 个主角。
3. **背景**（map）：地点、家族、势力，用城池、地名牌、版图拼合交代清楚；配一个标题条点出这一段的“比喻”。
4. **事件**（map）：年份牌 + 人物走动 / 箭头 / 打叉；第一次出场的重要人物配人物卡；有名言就配史料卡。
5. **转折 / 结果**（map）：版图换色、交战双刀、红印。
6. **总结**（balance / list）：一句话的对比或几条要点。
7. **结尾**（map）：留悬念，人物冒问号、换表情，红色标题条。

现代比喻（入股、重组、合伙人、天使投资……）适合放在红印和标题条上，画面会很有记忆点。

## 9. 检查结果怎么看

- `npm run check`：最后出现 **“✓ 格式正确”** 和 **“✓ 排版检查通过”** 就是通过。中间带 ⚠ 的是提醒（不挡出片，但最好改）；带 ✗ 的是错误（必须改，修改要求同时写在 `out/错误信息.txt`）。
- `npm run preview`：读 `out/<标题>-画面报告.txt`。**里面没有任何 ⚠ 开头的行 = 通过**，最后一行是“排版检查通过”。
- `out/` 里的文件都按视频标题命名，以前做的视频不影响新视频，可以不管也可以删。

## 10. 常见错误

- when 写了口播里没有的词（例如口播是“曹孟德”，when 写“曹操”）→ 改成这段里原样出现的词。
- 地名不在表里 → 换表里的地名或写 `[经度, 纬度]`。
- 把整段文案塞进一个 map → 拆成几段，每段画面不同。
- 同一段写了 person 又写 source → 只留一个。
- 改了文案的标点 / 错别字 → 不行，script 必须和原文一字不差。
